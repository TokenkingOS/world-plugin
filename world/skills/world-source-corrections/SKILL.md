先核当前本人和公司，用 `world_app_sources_impact` 读取准确 import 的实际来源变化、字段 key/组件位置、相关请求 digest/key、原回执与当前质量。依据实际 event/version/hash 追溯；显示名称可能重复，不能据名称猜组件。

## 已登记更正

向本人说明来源变化影响哪个准确请求，区分原请求已提交、尚未执行和仅发现回执尚待核验。impact 的当前依据和 historical_result 分别报告；旧回执及原确认保留为历史，不能当对新内容的认可。

用 impact 返回的原 `expected_version` 和 `change_digest` 调 `world_app_sources_reconcile`。它只核对已有 world 变化并追加工作流元数据：未执行准确请求停止，已提交请求保留，相关请求共用可追溯的复核事项。此调用不决定新的 Task 字段，也不撤销正式门。版本或指纹冲突时重新读取影响；重复原调用只找回原核对结果。

处理复核事项时读取当前 Task、现有更正事件和准确字段。需要修改时，沿 Task 准备入口生成带新来源/基线/参数的新请求，再挂到复核工作项。展示当前值、拟值和所需角色，由当前有权本人针对新 digest 明确决定；原确认不随替换请求迁移。提交后核对真实字段、业务状态及当前来源质量，最后读取 impact 确认复核事项的最新状态。

## 来源关系未明或事实迟到

没有已登记 lineage 的新版本、口头撤回及未协定会议 v2 保持具体 pending，给出缺口和处理人。旧来源被更正，不代表任意 v2 已有效。读取权、转存许可与字段业务决定分别核对；Source 选择及普通 correction 不扩展角色、服务主体或正式撤回权限。

需要登记来源更正说明时，沿既有普通事实路径，由当前有权人审阅准确原事件、事实时点和必要说明；其效力是更正依据。正式决定仍由原有业务门处理。原始会话和完整纪要留源；本技能的两个工具只传 import 定位、版本和指纹。

迟到资料保留真实 occurred_at。已有较新来源的字段由原 Task 检查拒绝覆盖；保留当前快照中仍有效的块、属性、材料和引用，在待办说明冲突位置。状态写入继续保持未经正式确认的性质，不能以普通事件或状态文字替代完成门。

同人跨 Agent 直接读取共享工作项和 impact。只读身份读取合法历史；授权失效或源变化阻止新写，不能借其他身份或换 key 恢复旧动作。工具尚未接通时说明能力缺口，正常业务流程不要求用户改用终端。
